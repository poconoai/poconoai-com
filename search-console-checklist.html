3 — Step-by-Step Submission Checklist

  • Step 1: Log in to Google Search Console for poconoai.com.
  • Step 2: Go to Sitemaps panel → add https://poconoai.com/sitemap.xml if not already submitted. Check for any errors or warnings.
  • Step 3: URL Inspection → enter https://poconoai.com/sentinel-node.html → Request Indexing. Confirm Google can render the page (check screenshot).
  • Step 4: Repeat URL Inspection → Request Indexing for each new concept page: zero-telemetry-ai.html, zero-exfiltration-ai.html, local-ai-inference.html, data-sovereignty-ai.html, ai-governance-layer.html, regulated-ai-infrastructure.html.
  • Step 5: URL Inspection → Request Indexing for updated hub pages: index.html, day-in-the-clinic.html, physicians-hub.html, attorneys-hub.html, governance.html, trust.html, research.html, investors.html.
  • Step 6: Check Coverage report for any Excluded or Error pages. Confirm breach-calculator.html, comparison.html, competitive-analysis.html appear as "Excluded by noindex" — this is intentional.
  • Step 7: Check Enhancements → Breadcrumbs (should show physicians-hub, attorneys-hub and other hub pages with BreadcrumbList schema).
  • Step 8: Check Rich Results Test at search.google.com/test/rich-results for sentinel-node.html (Product schema) and each concept page (FAQPage schema).
  • Step 9: Bookmark the Performance → Search Results view filtered to poconoai.com. Return in 4 weeks to establish impression baselines.
  • Step 10: Set a calendar reminder for 6 weeks post-deploy to run Stage 5C: review impressions and identify pages ranking position 20–80 for refinement.

4 — Crawl Health Monitoring

Check these metrics in Search Console monthly, or after any site update.

Excluded pages Coverage → Excluded breach-calculator, comparison, competitive-analysis should appear here as "noindex." 404 and utility pages also expected excluded.
Concept cluster impressions Performance → filter by URL Each of the 7 concept pages should show impressions within 4–8 weeks of indexing. Zero impressions at 8 weeks = title/content signal problem.
day-in-the-clinic.html Performance → filter by URL Original AI result trigger. Should show impressions and some clicks from medical practice queries. Watch for position trend.
Brand query impressions Performance → Queries → filter "Pocono AI" Branded impressions should be stable or growing. Position 1–3 expected for exact brand. Drops indicate indexing or penalty issues.
Core Web Vitals Core Web Vitals report All pages are static HTML with minimal JS — should pass. Flag any LCP > 2.5s.
Manual actions Security & Manual Actions Should always show "No issues detected." Check monthly.
Rich results eligibility Enhancements → FAQs, Breadcrumbs, Products 7 concept pages carry FAQPage schema. 5 hub pages carry BreadcrumbList. sentinel-node.html carries Product schema. These should appear in enhancements.

5 — Stage 5C Trigger Conditions

Stage 5C is data-driven refinement. Do not begin it until these conditions are met:

  • At least 4 weeks have elapsed since sitemap submission.
  • Search Console Performance shows impressions for at least 3 concept pages.
  • At least one query cluster is identifiable (brand, concept, or use-case) with position data.
  • Coverage report shows no unexpected Errors in the Valid/Excluded breakdown.

When these conditions are met, export the Performance → Queries CSV and bring it to Stage 5C. Do not refine pages without query evidence.
