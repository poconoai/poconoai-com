Plugin 1 — Available Now

🧠 Marcus's Memory Helper

The first Rehability plugin. Six local-first assistive tools for pain management, appointment prep, medication tracking, letter drafting, daily memory, and call summaries. Private. Draft-only. No cloud.

Express interest → See all six tools
Why this exists: I built it because I needed it. When you're managing chronic pain and cognitive overload, the things that should be easy — writing down what happened, preparing for an appointment, tracking what you tried — become genuinely hard. I needed tools that work when I'm lying down on my phone, in pain, with limited energy. So I built them. These are the tools I use. Generalized so others can use them too.
What It Is

A plugin under Sentinel Home / Rehability.

Marcus's Memory Helper is a bounded, purposeful plugin. It runs locally. It stores your data locally. It doesn't call the cloud. Every output it produces is a draft — you review it, you approve it, you decide what to do with it.

Local-first storage No cloud LLM calls No internet required human_review_required = true on all exports PDF / Markdown export Audit trail to Core Non-medical boundary Large-button accessible UI

Designed for hard days.

Active Tools

Six tools. Built and available.

Each tool is a bounded module. It does one thing. It produces one kind of output. All outputs require human review before any action is taken.

🩺

Pain Episode Capture

Available

When you're hurting and need to record what's happening before you forget — before the details blur, before the flare passes and you can't remember the specifics. Captures pain level, location, duration, suspected triggers, what you tried, what helped, what didn't.

  • Structured JSON record
  • Plain-English symptom note and timeline
  • Doctor-ready concise paragraph
Not emergency triage or diagnosis. If you have red-flag symptoms, seek emergency care. This tool does not replace that judgment.
📋

Medical Appointment Prep

Available

Turns recent notes and current state into a structured visit package. Because appointments are short and you're often not at your best when you get there. Helps you use your limited time with the clinician effectively without having to improvise.

  • Top concerns ranked by urgency
  • Concise agenda for the visit
  • Questions to ask
  • One-page visit summary
  • What to bring checklist
  • Follow-up tracking list
Patient communication support only. You or your clinician decides what matters clinically. Does not diagnose or recommend treatments.
✉️

Doctor / Advocate Letter Builder

Available

Creates letters to pain specialists, neurologists, hospitals, insurance advocates, patient advocates, and specialist referrals. Professional, factual, non-accusatory by default. Designed to help you say what you need to say clearly when pain, fatigue, or cognitive load makes writing hard.

  • Short letter (primary)
  • Fax-friendly plain text version
  • Email version
  • Bullet summary
Draft letter only. Human review required before sending. Tool separates patient-stated facts from medical conclusions and never invents clinical records.
💊

Medication / Treatment Trial Tracker

Available

Tracks medications, supplements, or treatments you've tried — dosing, timing, effects, side effects, start and stop dates. Builds a timeline. Produces a comparison table when you've tried multiple things. Generates a clinician briefing paragraph from what you reported.

  • Structured trial record per medication or treatment
  • Plain-English timeline
  • Comparison table (when multiple trials exist)
  • Clinician briefing paragraph
Patient-reported experience only. Does not tell you to start, stop, or change any medication. Does not interpret results clinically. All medication decisions require clinician supervision.
📓

Daily Memory Log

Available

Simple daily capture of what happened, how you felt, tasks, calls, and promises — structured so it can be reviewed, searched, and carried forward to the next day without losing context. For people whose memory doesn't reliably hold the day's detail.

  • Structured JSON log entry
  • Readable daily summary
  • Next-action list (carry-forward)
  • Carry-forward reminders for promises and pending tasks
Memory support tool only. Not a clinical documentation system. Not a substitute for professional memory assessment.
📞

Conversation / Call Summary

Available

Turns rough notes from a call, appointment, investor meeting, or technical session into a clean, searchable, action-ready summary. Built for voice-to-text input — for people who dictate notes or can't type quickly when they're in a call.

  • Structured JSON record
  • Clean written summary
  • Action item list
  • Follow-up tracking list
  • Next-session prompt (for recurring conversations)
Records what was said; does not interpret clinical content. Human review required before acting on any recorded commitments.

How It Works

Local AI. Your device. Your data.

Marcus's Memory Helper runs as a plugin under the Sentinel Node local AI runtime. No subscriptions, no cloud dependencies, no one else reading your notes.

1

You run the tool

Choose a tool — Pain Capture, Appointment Prep, etc. The plugin runs locally on your device. No internet connection required.

2

You review the draft

Every output is a draft. The system shows it to you before anything leaves the tool. You confirm, edit, or discard it.

3

You choose what to do with it

Export to PDF, save to Markdown, print for a clinician, or keep it local. Your decision, your export, your data.

4

Audit trail stays local

Every action is logged locally — what was created, when, by whom, and what review status it carried. No telemetry to any external server.
