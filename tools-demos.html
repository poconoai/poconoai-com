Sentinel Node Tools & Demos · Interactive Proof

Proof, not toys.

Every tool here is meant to be used, not admired. Run the actual retrieval-and-citation workflow, walk a governed scenario end to end, and put real numbers against your own liability, operational, and breach exposure. If a claim matters, there is something on this page you can interact with to test it.

About these tools. Everything on this page is a public, educational demonstration. The simulators, calculators, and walkthroughs use synthetic or illustrative data and pre-set responses to show how the Sentinel Node design behaves. They are not production systems, not connected to any live patient or client data, and their outputs are not clinical, legal, financial, or compliance advice.
